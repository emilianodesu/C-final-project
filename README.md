## Convención de commits

> \[Módulo]\[Especificación]\[Autor] Descripción del commit

### Módulos

- **readme**: README.md
- **gitignore**: .gitignore
- **makefile**: makefile (para compilar el proyecto automáticamente)
- **main**: Archivo principal del proyecto
- **headers**: Archivos de cabecera
- **src**: Archivos fuente del proyecto
- **productos**: Archivo de productos

### Banderas

- **add**: Se está añadiendo algo nuevo a este rubro
- **remove**: Se está eliminando algo de este rubro
- **update**: Se está trabajando en este rubro, pero no está terminado
- **fix**: Arreglar errores en este rubro
- **completed**: Este rubro está terminado

## Instrucciones de uso

- Ejecuta el siguiente comando para compilar el proyecto (asegúrate de estar en la carpeta raiz del proyecto):

```bash
make
```

- Para ejecutar el proyecto, utiliza el siguiente comando:

```bash
make run
```
